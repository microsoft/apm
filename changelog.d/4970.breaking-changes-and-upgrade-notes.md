- **BREAKING:** A dependency `ref` must name an origin branch or tag exactly, and a pinned commit must be reachable from one (checked once, online). APM now refuses a ref that matched only by its tail (for example `feature` for `refs/heads/team/feature`), a ref that only resolved through the old first-SHA fallback (for example `head` or `pull/7/head`), and a name that is both a branch and a tag. To fix, use the exact branch or tag name (`refs/heads/<name>` or `refs/tags/<name>` when both exist), or a commit on a branch or tag (#4970)
