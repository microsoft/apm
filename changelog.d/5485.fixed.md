- A local package outside the project root but in the same Git repository (a monorepo sibling), or, with no repository, sharing a parent directory with the project other than `/`, a drive root, or your home directory or its parents, is recorded in `apm.lock.yaml` relative to the project root (`../`), not by its absolute checkout path, so clones at different paths write byte-identical lockfiles, including MCP omission evidence. Upgrade note: lockfiles with the absolute form keep working with `--frozen`; the next `apm install` re-keys those rows once, keeping their owners and MCP selections; MCP servers approved under the old absolute key must be approved again once (`apm approve local:<relative path>`); a stale `apm_modules/_local` cache directory may remain, and `apm prune` or deleting `apm_modules` is safe.
