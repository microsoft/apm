This journey is for a package author or a central platform team. Your job: ship
agent capabilities that other teams depend on, pin and update on their own
schedule, without copies drifting apart in every repository.

A package is a git repository APM can install. Tag a release and consumers write
`your-org/your-package#v1.2.0` in their `apm.yml`. Their lockfile records the
exact commit, and each fix you ship reaches them as a Dependabot or Renovate pull
request they review and merge.

**You need:** APM ([install it](../getting-started/installation/)) and a git
repository you can push tags to.
