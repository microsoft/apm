This journey is for a developer or tech lead in one repository. Your job: give
the team the same agent setup everywhere and keep it current, with no
surprises.

APM records the skills, instructions, plugins and MCP servers your agents load
in a manifest (`apm.yml`) and a lockfile (`apm.lock.yaml`). Commit both, and
every clone and CI run installs the same files, checked against the lockfile.
