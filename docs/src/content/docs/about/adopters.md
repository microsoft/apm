These organizations and projects have asked to be listed. Inclusion records usage, not
endorsement. The source of truth is
[ADOPTERS.md](https://github.com/microsoft/apm/blob/main/ADOPTERS.md).

| Organization | Type | How they use APM |
|---|---|---|
| ENCAMINA | Consultancy, end user | Governs skills, instructions, agents and MCP configurations across initiatives in Azure DevOps and GitHub. |
| EPAM | Consultancy, contributor, end user | Uses, contributes to and consults on APM. |
| Grupo Universal | End user | Packages and distributes agent skills, prompts and MCP configurations across internal projects. |

## Add your organization

No issue or approval is needed. Fill in the
[adopter form](https://github.com/microsoft/apm/issues/new?template=adopter.yml) and a maintainer
opens the pull request for you, or open a one-row pull request to ADOPTERS.md yourself. You can
list an anonymous description, such as "A global insurer", if your name cannot be public.

## Beyond this list

Many teams use APM without asking to be listed. As of November 2026, a GitHub code search finds
`apm.lock.yaml` committed in roughly 900 public repositories, about a quarter of them owned by
organizations. Private repositories are not counted.
